# Background music (optional)

এই ফোল্ডারে কপিরাইট-মুক্ত `.mp3` গান রাখলে ভিডিওর পেছনে খুব আস্তে বাজবে।
একাধিক ফাইল থাকলে প্রতিটা ভিডিওতে একটা করে বেছে নেওয়া হবে।

ফ্রি গান পাবে YouTube Studio → **Audio Library** থেকে (ডাউনলোড করে এখানে আপলোড করো)।
গান না রাখলে শুধু ভয়েস থাকবে, তাতেও কোনো সমস্যা নেই।
